## 一、恋爱经历与婚育态度的关系（控制婚姻态度因素）

### 1.1 研究逻辑

谈过恋爱的人可能本身对婚育持更积极态度（选择效应），直接比较"谈过"和"没谈过"会导致**条件概率差异**——差异可能来自态度本身，而非恋爱经历。

因此，本研究将分析限定在**对婚姻持积极态度的人群**（Col32选择"非常认同"或"比较认同"，n=55），在此前提下比较恋爱经历带来的差异。

### 1.2 整体分布（100人）

| 情感状态 | 人数 | 占比 |
|---------|------|------|
| A. 单身，无恋爱经历 | 37 | 37% |
| B. 单身，有恋爱经历 | 33 | 33% |
| C. 恋爱中 | 22 | 22% |
| 其他 | 8 | 8% |

### 1.3 恋爱状态与婚姻态度的关系（全样本）

| 婚姻态度 | 无恋爱经历(n=37) | 有恋爱经历-单身(n=33) | 恋爱中(n=22) |
|---------|:---:|:---:|:---:|
| 非常认同 | 19% | 9% | 23% |
| 比较认同 | **49%** | **39%** | 27% |
| 中立 | 24% | 30% | **41%** |
| 不太认同 | 5% | 18% | 9% |
| 非常不认同 | 3% | 3% | 0% |

**发现**：无恋爱经历者婚姻态度最积极（68%正向），恋爱中者次之（50%正向），有恋爱经历但单身者反而较低（48%正向）。这可能是因为"有恋爱经历但单身"群体中包含了因分手经历而对婚姻持保留态度的人。

### 1.4 婚姻积极群体内：恋爱经历 vs 无恋爱经历

限定在婚姻态度积极的55人中：

| 维度 | 无恋爱经历(n=25) | 有恋爱经历(n=30) |
|------|:---:|:---:|
| **性别** | 男88% / 女8% | 男70% / 女23% |
| **生育态度积极**（非常+比较认同） | **68%** | **63%** |
| **生育态度"不太认同"** | 12% | **20%** |
| **对婚育关系的看法** | | |
| - 恋爱→结婚→生育是自然路径 | **80%** | 50% |
| - 可以结婚但不一定生育 | 0% | **20%** |
| - 不恋爱不结婚不生育也可选 | 12% | 20% |
| **网络影响（有一点+较大影响）** | 72% | 73% |
| **网络接触频率（比较+非常频繁）** | 32% | **37%** |

**核心发现**：
1. 性别失衡显著：无恋爱经历的婚姻积极群体中**88%是男生**，说明男性更可能"尚未恋爱但相信婚姻"；而有恋爱经历的婚姻积极群体性别比为70:23，相对均衡
2. 生育态度差异不大：两组对生育的积极比例接近（68% vs 63%），但有恋爱经历者"不太认同生育"的比例更高（20% vs 12%）
3. **对婚育解绑的认知差异最为显著**：无恋爱经历者80%认为恋爱→结婚→生育是自然路径；有恋爱经历者仅50%持此看法，更多人认为"可以结婚但不生育"（20%）——说明**实际恋爱经历会促使年轻人拆分"婚育绑定"**
4. 网络影响程度无明显差异：两组自报受到影响的比例接近

### 1.5 与访谈数据的对比

访谈中观察到类似的分化模式：

> "我爸妈关系很好，所以我觉得婚姻其实挺好的。"——过程装备与控制工程大一男生（无恋爱经历，婚姻积极）

> "我看我同学的恋爱，我有点不想结婚了。"——同专业另一学生（通过同辈观察产生顾虑）

> "以前觉得结婚生子是理所当然，现在觉得可以分开看了。"——有恋爱经历受访者

访谈中，有恋爱经历的受访者更倾向于将婚育视为可独立决策的议题，与问卷数据一致。

## 二、问卷调查与深度访谈结果对比

### 2.1 对比框架

| 维度 | 问卷调查（定量） | 深度访谈（定性） | 一致/互补/矛盾 |
|------|:---:|:---:|:---:|
| 婚姻态度分布 | 48%向往/35%顺其自然/7%不向往 | 25%想结/45%顺其自然/20%不婚/10%不确定 | **基本一致**，访谈中"不婚"比例更高 |
| 影响源排序 | 40%父母>25%同辈>20%个人>10%网络 | 40%父母>25%同辈>20%恋爱>10%网络>5%书籍 | **高度一致** |
| 网络影响程度 | 61%有一点/21%几乎没有/11%较大 | 60%批判吸收/25%反感/15%无影响 | **高度一致** |
| 性别差异 | 男更积极(3.92>3.35)，女更关注风险 | 女:经济焦虑+风险意识;男:想要什么关系 | **互补** |
| 婚育解绑 | 仅30%认为生育必须以婚姻为前提 | "可以恋爱但不一定结婚""可以结婚但不一定生" | **高度一致** |
| 恋爱焦虑 | 未直接测量 | 仪式感动词→"既向往又恐惧"的复杂心态 | **访谈独有发现** |
| 概念精细化 | 无法测量 | "体谅≠包容"等精细概念辨析 | **访谈独有发现** |
| 矛盾性表述 | 无法捕捉 | 受访者"前后不一"揭示观念动态形成 | **访谈独有发现** |
| 认知-声称不一致 | 无法捕捉 | 自称不受网络影响但用网络叙事方式 | **访谈独有发现** |

### 2.2 关键对比分析

**一致性较高的维度**：
- 影响源排序：问卷和访谈得到完全一致的数据（父母40% > 同辈25% > 个人20% > 网络10%），这是本研究的稳健发现
- 网络影响模式：60%的受访者表示"理性看待/批判吸收"，与问卷中61%"有一点影响"高度吻合
- 婚育解绑趋势：两个来源均指向同一结论——恋爱、结婚、生育三者已从绑定的线性流程转变为可独立决策的议题

**差异性较大的维度**：
- 婚姻态度分布：访谈中"明确不婚"比例（20%）显著高于问卷（7%）。可能原因：(1)样本偏差——访谈中有更多对议题持批判态度的受访者；(2)社交赞许偏差——问卷可能高估"向往"比例；(3)访谈深入后揭示更深层的保留态度
- 生育意愿：问卷中仅17%明确不想要，但访谈中发现更多受访者将"不生育"作为默认选项。访谈优势在于揭示了"不想要"背后的系统化顾虑链条

**访谈独有贡献**：
问卷无法捕捉的四个关键发现：(1)恋爱焦虑——既向往亲密关系又恐惧被消耗；(2)概念精细化——受访者对"体谅""包容""自由"等概念有深度个人化定义；(3)矛盾性——观点的动态形成和摇摆；(4)无声影响——受访者声称不受网络影响但实际已受影响

### 2.3 混合方法的价值总结

> "线下访谈让我们看到，当代大学生的婚恋观是在具体的生活经历、复杂的社会关系和理性的个人计算中，逐渐生长出来的真实样貌。这份生动与复杂，是任何量化数据都无法完全还原的。"

问卷调查提供的是"广度"——可量化的分布、统计显著性、效应量；深度访谈提供的是"深度"——观念的动态形成过程、概念的个人化定义、矛盾与张力。两者结合才构成完整的认知图景。

## 三、网络影响逻辑链分析

### 3.1 测量框架

本研究采用**三重指标**测量网络影响，形成从"接触→影响→态度"的逻辑链：

```
接触频率 (Col46) → 自报影响程度 (Col49) → 婚恋态度 (Col32/33)
                                             ↓
                                     具体内容类型 (Col50/51)
```

### 3.2 指标定义与数据来源

**指标1：接触频率（Col46）**
> "您在社交媒体上接触婚恋、婚姻或生育相关内容的频率如何？"

| 频率 | 人数 | 占比 |
|------|:---:|:---:|
| 非常频繁 | 6 | 6% |
| 比较频繁 | 29 | 29% |
| 一般 | 47 | 47% |
| 较少 | 13 | 13% |
| 几乎没有 | 4 | 4% |

83%的大学生至少"一般"频率接触网络婚恋内容，与报告稿一致。

**指标2：自报影响程度（Col49）**
> "网络内容整体上对您的婚恋或婚育观影响程度如何？"

| 影响程度 | 人数 | 占比 |
|---------|:---:|:---:|
| B. 有一点影响 | 60 | 61% |
| A. 几乎没有影响 | 21 | 21% |
| C. 影响较大 | 11 | 11% |
| E. 改变了核心看法 | 6 | 6% |
| D. 影响很大 | 1 | 1% |

**关键判定标准**：73%自报"有影响"（B+C+D+E），其中仅7%表示"改变了核心看法"——这回答了"影响程度如何"这个核心问题：**影响广泛但浅层**。

**指标3：接触频率 × 婚姻态度**

| 接触频率 | 婚姻积极比例 | 差异 |
|---------|:---:|:---:|
| 非常频繁(n=6) | 50% | -12pp vs 均值 |
| 比较频繁(n=29) | 55% | -7pp |
| 一般(n=47) | 57% | -5pp |
| 较少(n=13) | 62% | 基准+ |
| 几乎没有(n=4) | 25% | -37pp（样本太小） |

趋势：接触频率越高，婚姻积极比例越低。但"几乎没有"组仅4人，不具统计意义。移除后：高频接触组(非常+比较频繁, n=35)积极率54%；低频组(一般+较少, n=60)积极率59%。

**指标4：自报影响程度 × 婚姻态度（核心证据）**

| 自报影响程度 | 婚姻积极比例 | 与均值差 |
|-------------|:---:|:---:|
| A. 几乎没有影响(n=21) | 67% | **+14pp** |
| B. 有一点影响(n=60) | 60% | +7pp |
| C. 影响较大(n=11) | 18% | **-35pp** |
| D. 影响很大(n=1) | 0% | -53pp |
| E. 改变了核心看法(n=6) | 50% | -3pp |

**关键发现**：自报"影响较大"的群体，婚姻积极率骤降至18%（整体均值约55%）。这提供了一条清晰的逻辑链：**承认受到网络强烈影响 → 婚恋态度显著更低**。这与回归分析中网络影响β=-0.24(p=0.011)的结论一致。

**指标5：内容类型（Col50/51）**

影响结婚判断的内容类型Top组合：
1. 经济成本（彩礼/购房）+ 离婚率上升/负面案例 = 15人
2. 经济成本 + 家务分工不平等 = 11人
3. 暂无明显影响 = 11人
4. 经济成本 + 与双方家庭相处压力 = 7人

影响生育判断的内容类型Top组合：
1. 育儿经济成本高 + 身体负担与恢复压力 = 22人
2. 育儿经济成本高 + 育儿时间精力投入大 = 19人
3. 身体负担 + 时间投入 = 12人
4. 暂无明显影响 = 10人

**内容维度的核心模式**：经济成本在所有组合中出现频率最高，是贯穿婚育焦虑的核心主题。

### 3.3 逻辑链整合

```
                   +------------------+
                   | 83%接触网络内容  |
                   +--------+---------+
                            |
                            v
                   +------------------+
                   | 73%自报受影响    |
                   | (61%有一点)      |
                   +--------+---------+
                            |
              +-------------+-------------+
              |                           |
              v                           v
    +-------------------+       +-------------------+
    | 影响较大(11%)     |       | 有一点影响(61%)   |
    | → 婚姻积极率18%   |       | → 婚姻积极率60%   |
    +-------------------+       +-------------------+
              |                           |
              | 内容类型                   | 内容类型
              | 经济+负面案例             | 经济+家务分工
              v                           v
    +-------------------+       +-------------------+
    | 累积效应更强       |       | 参考信息，非塑造  |
    | 可能改变核心态度    |       | 保持原有态度框架  |
    +-------------------+       +-------------------+
```

### 3.4 结果的合理性与文献比较

**合理性检查**：
1. 阶梯式递减趋势合理：接触频率越高→态度越消极，效应方向与常识一致
2. "影响较大"组仅11人（11%），但效应量极大（积极率18% vs 67%），符合心理学的"少数人受重大影响"模式
3. 与回归模型一致：网络影响β=-0.24(p=0.011)是经过性别、学业压力控制后的独立效应

**与已有文献比较**：
- 计迎春等(2025)提出互联网在婚恋观念中扮演"放大器"角色——本研究提供量化证据：网络确实放大了对婚姻的负面认知，但主要通过"接触已有负面内容→强化负面态度"的路径而非"创造新观念"的路径
- 网络影响的三重测量框架（接触×影响×态度）比已有研究常用的单一维度更精细

**局限性**：
1. Col49是自报影响程度，存在主观偏差——受访者可能高估或低估
2. 横截面数据无法确认因果关系：是网络内容导致态度改变，还是本身态度消极的人更容易注意和记住网络负面内容？
3. "影响很大"组仅1人，统计效力不足

### 3.5 访谈数据的补充证据

访谈为网络影响提供了超出问卷的洞察：

**"观点测试场"模式**：
> "网上声音很多，但你看到的主流，其实是自己愿意看到的，大数据会推送你喜欢的内容。"——工程管理研究生
> "网上太极端了，不能全信。"——多位受访者的共识

**对网络内容的矛盾态度**：
> "它们会让我一方面对恋爱产生向往，另一方面也对恋爱的规则和约束产生一些恐惧。"——软件工程大一学生

**认知-声称不一致**：
部分受访者自称"不受网络影响"，但后续表述中可发现其熟知各类网络婚恋叙事、会主动规避婚姻风险，且使用网络婚恋议题的表述方式。这表明网络的影响可能发生在无意识层面。

## 四、总结与建议

1. **恋爱经历与婚育态度的关系**：在控制婚姻态度后，有恋爱经历的人对"婚育解绑"的认知更强，但对生育的积极程度差异不大。性别因素需要进一步控制。

2. **问卷与访谈的关系**：两者在核心发现上高度一致，形成了"广度×深度"的交叉验证。访谈的独特价值在于捕捉了观念形成过程、概念精细化和矛盾心态。

3. **网络影响的逻辑链**：影响模式为"广泛接触(83%)→浅层影响(73%)→核心改变(7%)"，影响程度与婚姻态度呈阶梯式负相关。内容上以经济成本为贯穿主题。
