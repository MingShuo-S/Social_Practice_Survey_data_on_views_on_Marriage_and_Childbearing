# "你…还向往吗？" — 当代大学生婚恋观社会调查

本仓库包含南京大学社会实践项目"呢喃知音——婚恋观调查"的公开研究数据与成果。

## 项目简介

本项目采用混合研究方法，对当代大学生的婚恋观、生育观及其影响因素进行了系统性调查。

- **定量数据**：三批次网络问卷，合计174份有效问卷
- **定性数据**：40份标准化深度访谈
- **覆盖高校**：南京大学、东南大学、上海交通大学、复旦大学等

## 数据说明

### 问卷数据

三批问卷通过问卷星平台收集：

| 批次 | 简称 | 样本量 | 说明 |
|------|------|:------:|------|
| 第一批 | v1 | 17 | 初始版本，含婚姻态度、生育顾虑、网络影响等 |
| 第二批 | v2 | 58 | 扩充结构版，含详细婚育态度 |
| 第三批 | v4 | 100 | 完整版，新增Likert量表、非传统关系模式题 |

**脱敏处理**：原始问卷包含提交时间、填写时长、来源渠道、IP地址等个人标识信息，已在CSV文件中移除上述列。

**数据使用注意事项**：
- CSV文件为UTF-8-BOM编码
- 所有百分比、均值、统计检验值需自行计算
- 第三批(v4)问卷包含78道题，为最完整版本

### 访谈数据

40余份深度访谈采用标准化半结构化访谈框架，涵盖：
- 理想关系描述
- 长期关系底线条件
- 结婚意愿与态度
- 影响源（家庭、同辈、网络）
- 网络婚恋内容与现实想法的对比

访谈由三個小组分批次执行：
- **许金鹏&袁愿组**：5.10/5.17/5.23，南大校内
- **徐新飞&邵波岚组**：5.10，南大校内  
- **曾溢玮&张书源组**：5.10/5.17，南大校内
- **曹鑫&徐庆广组**：5.17/5.20，跨校（南大、东南、复旦、上交）

**脱敏处理**：采访者姓名使用代号，受访者使用编号，移除一切可识别个人身份的信息。

## 核心结论

1. **中等向往但非必选**：48%向往婚姻，但71%认同婚姻非人生必备
2. **婚育解绑**：恋爱、结婚、生育从绑定的线性流程转变为可独立决策的人生议题
3. **性别差异显著**：男性对婚姻更积极，女性更关注经济条件和风险感知
4. **父母婚姻质量关键因素**：效应量最大（Cramer's V=0.31）
5. **网络影响广泛但浅层**：83%接触、73%自报受影响、仅7%改变核心看法
6. **大学生不是被动接收者**：以"观点测试场"模式与网络信息互动
